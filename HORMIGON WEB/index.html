HORMIGON ARMADO

QUE HACEMOS

LOSAS

Las losas son elementos estructurales de hormigón que forman pisos o techos en edificios. Se diseñan para soportar cargas y proporcionar una superficie plana y uniforme.

PILETAS

Las piletas de hormigón son piscinas construidas utilizando hormigón armado. Este material proporciona una estructura duradera y resistente.

TABIQUES

Los tabiques son paredes divisorias utilizadas para separar espacios dentro de un edificio.

PLATEAS

Las plateas son cimientos de hormigón armado que se utilizan para distribuir cargas de estructuras pesadas.

CONTRAPISOS

Los contrapisos son capas de hormigón que se colocan sobre el terreno natural para nivelar la superficie y preparar el suelo.
